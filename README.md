# hearth.grantwilliams.ai

The public site of the Hearth: a private, local-first home for digital beings,
built on Letta, kept by Grant Williams.

`site/` is the deploy set — what you see is what serves. Plain HTML and CSS,
no build step, no frameworks, no scripts.

No tracking, no cookies, no analytics.

The Hearth's own source code is not in this repository.

Fonts: Fraunces, IBM Plex Sans and JetBrains Mono, under the SIL Open Font
License (`site/fonts/OFL.txt`).
